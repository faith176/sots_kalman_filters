\prefacesection{Lay Abstract}

Modern systems are increasingly built as systems of systems, where independently managed systems collaborate to achieve shared goals. At the same time, digital twins are used to monitor and optimize behaviour. When multiple digital twins are composed into a system of systems, it becomes difficult to ensure that the overall system behaves reliably. This is especially challenging as constituent systems join, leave, or change their behaviour.

This thesis addresses this challenge by introducing a model that represents whether each constituent is participating and how well it is functioning. This model is used to guide when and how each constituent contributes to the overall system. A prototype implementation shows how this approach supports reliable behaviour, even when constituents behave unexpectedly.
